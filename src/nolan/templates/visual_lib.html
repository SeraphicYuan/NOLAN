Coverage
Naming a work searches the catalog; describing one searches the pictures. Both work — describing is where this beats keyword search. Filters narrow first, so a search runs against a far smaller set. Leave the box empty to just browse a filtered slice.
Curated collections
A set somebody chose — not everything an institution holds. Median size is 12 pictures, so a collection is a starting point rather than a corpus. Clicking one filters the Search grid to it.
Visual knowledge table
What is true of a maker, looked up once and spent across every work they made. Dates, nationality and movement come from Wikidata (marked ✓); style and palette come from a model, and the two are never mixed. Click a name to see their pictures.
Harvest from a source
One row per catalog record: identity, rights and a 512px thumbnail. Long by nature — ~900 Art Institute rows take ~25 minutes, and the Met costs an extra request per object — so it runs as a background job.
What has been harvested
A source is an institution's API; a collection is one harvest from it. A source can yield many — PDIA yields 577 curated sets, the museums one each. Rights live on the collection and are sticky: a later pass that knows nothing about them cannot overwrite them.

What this library actually knows
Every harvested row carries the institution's own catalog prose. A caption is different — a model reading the picture — and it is spent on demand, never in bulk, so the percentage below is usually small by design. Catalog prose deliberately does not count toward it: counting it would report an entirely un-captioned collection as complete.
